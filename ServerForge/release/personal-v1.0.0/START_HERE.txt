Welcome to ServerForge Personal Edition (v1.0.0).
ServerForge is a native Windows desktop control center paired with a Windows
Service Agent for managing your own Windows IIS servers and deployments.

No .NET SDK, no commercial license, no cloud account, and no PowerShell
commands are required for ordinary Desktop installation.

--------------------------------------------------------------------------------
1. WHICH INSTALLER GOES WHERE?
--------------------------------------------------------------------------------

  [A] On your Windows 11 PC (your control workstation):
      -> Run: ServerForge-Desktop-Setup.exe

  [B] On each Windows Server you want to manage (e.g., Windows Server with IIS):
      -> Run: ServerForge-Agent-Setup.exe (Right-click -> Run as administrator)

  NOTE ON WINDOWS SMARTSCREEN:
  These personal-use installers are unsigned (no commercial code-signing
  certificate). If Windows Defender SmartScreen shows "Windows protected your
  PC", verify the file hash in SHA256SUMS.txt, then click:
      "More info" -> "Run anyway".

--------------------------------------------------------------------------------
2. INSTALL & OPEN SERVERFORGE DESKTOP (ON YOUR WINDOWS 11 PC)
--------------------------------------------------------------------------------

  1. Double-click ServerForge-Desktop-Setup.exe.
  2. Follow the setup wizard (check "Create a desktop shortcut" if desired).
  3. Launch "ServerForge Desktop" from the Start Menu or Desktop shortcut.

  FIRST-TIME ADMINISTRATOR SETUP:
  - On first launch, the Setup Wizard creates your local administrator profile
    (username + password, minimum 8 characters) stored locally in SQLite and
    protected with Windows DPAPI under your Windows user account.
  - Note: After first-time setup completes, ServerForge Desktop opens directly
    into your Dashboard under your signed-in Windows account (it relies on
    Windows sign-in + CurrentUser DPAPI rather than a separate login screen on
    every launch).
  - You can skip GitHub and Server Pairing during the wizard and add them
    anytime from the sidebar.

--------------------------------------------------------------------------------
3. INSTALL & PAIR SERVERFORGE AGENT (ON YOUR WINDOWS SERVER)
--------------------------------------------------------------------------------

  1. Copy ServerForge-Agent-Setup.exe to your Windows Server.
  2. Right-click ServerForge-Agent-Setup.exe -> "Run as administrator".
  3. The installer registers and starts the "ServerForgeAgent" Windows Service.
     - It does NOT install IIS, open firewall ports, or touch existing IIS
       websites, AppPools, or databases.
     - By default, the Agent listens ONLY on 127.0.0.1:9443 (local-only) for
       safety.
  4. For a remote server, bind the Agent to your private VPN / Tailscale /
     WireGuard IP (NEVER 0.0.0.0 or a public internet IP) in:
       C:\Program Files\ServerForge\Agent\appsettings.json
     and allow TCP port 9443 in Windows Firewall ONLY from your Windows 11 PC's
     private IP. See INSTALLATION_GUIDE.md for exact copy-paste settings.
  5. Open the one-time pairing file generated by the Agent:
       C:\ProgramData\ServerForge\Agent\pairing-code.txt
     Note the One-Time Pairing Code and Server Certificate Thumbprint.
  6. In ServerForge Desktop, go to "Servers" (Ctrl+9) -> Add Server:
     - Enter your server's private/VPN IP, port 9443, pairing code, and
       pinned certificate thumbprint.
     - Click Pair. Desktop and Agent now communicate exclusively over
       certificate-pinned mutual TLS (mTLS).

--------------------------------------------------------------------------------
4. ADD AN IIS SERVER & DEPLOY YOUR FIRST APPLICATION
--------------------------------------------------------------------------------

  1. DISCOVER EXISTING IIS SITES SAFELY:
     - Open "Servers" (Ctrl+9) or "Domains & SSL" (Ctrl+6) and click Refresh.
     - Any pre-existing IIS sites are shown as "ReadOnlyUnmanaged" and will
       NEVER be modified or restarted unless you explicitly adopt them.

  2. CREATE A PROJECT & APPLICATION:
     - Go to "Projects" (Ctrl+2) -> Create a Project Group.
     - Go to "Applications" (Ctrl+3) -> Create an Application on your paired
       server (choose runtime, internal port, health check path, and branch).
     - Optionally configure Environment Variables (Ctrl+7); secret values are
       encrypted with Windows DPAPI and masked in the UI and logs.

  3. CONNECT GITHUB (OPTIONAL, FOR GITHUB ACTIONS DEPLOYMENTS):
     - Go to "GitHub" (Ctrl+4) and paste a Fine-Grained Personal Access Token
       with read-only access (Contents: Read, Actions: Read, Metadata: Read).
     - Authorize your target repository.

  4. DEPLOY, MONITOR & ROLLBACK:
     - Go to "Deployments" (Ctrl+5) to trigger a manual deployment or enable
       automatic GitHub Actions deployments.
     - Watch live deployment history, monitoring (Ctrl+M), and redacted logs
       (Ctrl+L).
     - If a new release fails health checks, automatic rollback restores the
       previous healthy release; you can also restore an earlier healthy
       release from Deployments / Releases.

--------------------------------------------------------------------------------
5. WHERE LOGS & LOCAL CONFIGURATION ARE STORED
--------------------------------------------------------------------------------

  ON YOUR WINDOWS 11 PC (DESKTOP):
  - Database & Settings: %LOCALAPPDATA%\ServerForge\serverforge-desktop.db
  - Backups:             %LOCALAPPDATA%\ServerForge\backups\
  - Logs:                %LOCALAPPDATA%\ServerForge\logs\desktop-*.log

  ON YOUR WINDOWS SERVER (AGENT):
  - Agent Config:        C:\Program Files\ServerForge\Agent\appsettings.json
  - Identity & State:    C:\ProgramData\ServerForge\Agent\
  - Pairing Code:        C:\ProgramData\ServerForge\Agent\pairing-code.txt
  - Agent Logs:          C:\ProgramData\ServerForge\Agent\logs\agent-*.log
  - Managed Apps Root:   C:\ServerForgeApps\

--------------------------------------------------------------------------------
6. HOW TO UPGRADE OR UNINSTALL SAFELY
--------------------------------------------------------------------------------

  UPGRADE:
  - Simply run the newer ServerForge-Desktop-Setup.exe or
    ServerForge-Agent-Setup.exe over your existing installation.
  - Desktop upgrades preserve %LOCALAPPDATA%\ServerForge.
  - Agent upgrades stop the service cleanly, preserve appsettings.json,
    pairing identity, certificates, and C:\ServerForgeApps, then restart.

  UNINSTALL:
  - Open Windows Settings -> Apps -> Installed apps -> Uninstall
    "ServerForge Desktop" or "ServerForge Agent".
  - Uninstalling Desktop preserves your local data in %LOCALAPPDATA%\ServerForge.
  - Uninstalling Agent removes ONLY the ServerForgeAgent service and binaries;
    it NEVER deletes C:\ServerForgeApps, hosted websites, IIS sites, or
    databases.

For full details and optional troubleshooting, open INSTALLATION_GUIDE.md.
